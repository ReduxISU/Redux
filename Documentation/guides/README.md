# Contributor guides: start here

Welcome. These guides explain, step by step, how to contribute to Redux. They are written for people new to the project, so do not worry if you have never done this before.

## Read these first

1. [Building and testing](building-and-testing.md): how to check your work before you push, and what to do when the automatic checks on your PR turn red.
2. [Adding a reduction](adding-a-reduction.md): how to add a new reduction between two problems, with a worked example.
